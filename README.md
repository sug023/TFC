# Casino Virtual

Proyecto web desarrollado para **2º SMR**, basado en un casino virtual con **moneda ficticia**.

El proyecto permite a los usuarios jugar a diferentes juegos utilizando **EuroDólares (`§`)**, sin ningún tipo de dinero real o transacción económica.

## Juegos

El casino contará con diferentes juegos:

* Dados
* Ruleta
* Mines
* Slots

Los juegos están diseñados de forma modular para facilitar la incorporación de nuevos juegos en el futuro.

## Usuarios

El sistema incluye:

* Registro e inicio de sesión.
* Verificación mediante correo electrónico.
* Nickname único.
* Perfiles públicos.
* Avatares personalizados.
* Cambio de contraseña.
* Historial de movimientos.
* Sistema de ranking.

## Sistema de moneda

El casino utiliza una moneda virtual propia:

> **EuroDólar — `§`**

El saldo se utiliza exclusivamente dentro de la aplicación para realizar apuestas y recibir premios.

No se utiliza dinero real.
