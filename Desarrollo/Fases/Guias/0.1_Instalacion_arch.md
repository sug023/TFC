# Instalación de Arch Linux

Esta guía describe el procedimiento seguido para realizar una instalación base de **Arch Linux** en una máquina virtual. El sistema instalado se utilizará posteriormente como base para los dos routers de la infraestructura, por lo que no se instalará ningún entorno gráfico.

La configuración específica de cada router, incluyendo **NetworkManager, enrutamiento, NAT e iptables**, se realizará posteriormente en sus respectivas guías.

## Requisitos

Para realizar la instalación de **Arch Linux** necesitaremos los siguientes elementos:

- Conexión a Internet.
    
- La imagen ISO de **Arch Linux**, descargada desde su página web oficial.
    
- **VirtualBox** para crear y ejecutar la máquina virtual.
    

## Creación y configuración de la máquina virtual

Antes de comenzar la instalación de Arch Linux, se creará una máquina virtual en **VirtualBox** con las características necesarias para el proyecto.

### Configuración básica

Se utilizará la siguiente configuración:

| Recurso           | Configuración   |
| ----------------- | --------------- |
| Sistema operativo | Linux           |
| Arquitectura      | 64 bits         |
| Memoria RAM       | 2 GB            |
| Procesador        | 1               |
| Almacenamiento    | 15 GB           |
| Firmware          | UEFI            |
| Entorno gráfico   | No se instalará |

Se seleccionará **Linux** como tipo de sistema operativo y una versión de **64 bits**. Es importante utilizar una arquitectura de 64 bits, ya que la ISO actual de Arch Linux requiere una CPU x86-64.

![[Instalacion_router_01.png]]

Se asignarán **2 GB de RAM**, **1 procesador** y se marcará la opción **Use EFI**. Al no utilizar un entorno gráfico, estos recursos serán suficientes tanto para la instalación como para los servicios que se ejecutarán posteriormente.

![[Instalacion_router_02.png]]

Para el almacenamiento se asignarán **15 GB** mediante un disco virtual de tamaño dinámico. Aunque una instalación básica puede realizarse utilizando menos espacio, se ha decidido disponer de margen suficiente para futuras instalaciones, paquetes y configuraciones.

![[Instalacion_router_03.png]]

Con las opciones configuradas correctamente, tras iniciar la máquina virtual se mostrará la siguiente terminal:

![[Instalacion_router_04.png]]
### Sistema

En **Configuración → Sistema → Placa base** se activará:
    
- **Reloj hardware en UTC**.

![[Instalacion_router_05.png]]

En **Configuración → Sistema → Procesador** se asignarán:
    
- **PAE/NX**: Habilitado.
      
- **VT-x/AMD-V**: habilitado.

![[Instalacion_router_06.png]]

En **Configuración → Sistema → Aceleración** se utilizarán las opciones de virtualización por hardware disponibles:
     
- **Paginación anidada**: habilitada.
    
- **Para virtualización**: `Predeterminada`.
    
![[iNSTALACION_ROUTER_07.png]]

La virtualización por hardware permite que la máquina virtual pueda utilizar correctamente las características de virtualización proporcionadas por el procesador físico.

#### Justificación de las opciones seleccionadas

Las opciones seleccionadas permiten que la máquina virtual disponga de un entorno de ejecución adecuado para **Arch Linux** y aproveche correctamente las capacidades de virtualización del equipo anfitrión.

- **Reloj hardware en UTC**: se utiliza para mantener una referencia horaria estándar en la máquina virtual y evitar problemas relacionados con la configuración de la hora.
    
- **PAE/NX**: se habilita para proporcionar al sistema invitado las funciones de gestión de memoria y protección de ejecución disponibles en el procesador.
    
- **VT-x/AMD-V**: permite utilizar la virtualización asistida por hardware del procesador físico. Es necesaria para que VirtualBox pueda ejecutar la máquina virtual de forma adecuada.
    
- **Paginación anidada**: mejora la gestión de la memoria virtual al permitir que el procesador físico gestione de forma más eficiente las direcciones de memoria utilizadas por el sistema invitado.
    
- **Para virtualización — Predeterminada**: permite que VirtualBox seleccione automáticamente el mecanismo de paravirtualización apropiado para el sistema operativo invitado.
    

En conjunto, estas opciones proporcionan la configuración necesaria para ejecutar **Arch Linux de forma estable y eficiente**, sin asignar recursos adicionales que no sean necesarios para el funcionamiento de los routers.
### Configuración de red

La configuración de los adaptadores dependerá de la función que tendrá la máquina dentro de la infraestructura.

Para **Router 1**, se utilizarán tres adaptadores:

| Adaptador   | Conectado a         | Función                          |                                      |
| ----------- | ------------------- | -------------------------------- | ------------------------------------ |
| Adaptador 1 | NAT                 | Acceso a Internet                | ![[Instalacion_router_08.png]]       |
| Adaptador 2 | Red interna `DMZ`   | Comunicación con el servidor Web | ![[Instalacion_router_09.png]] |
| Adaptador 3 | Red interna `R1-R2` | Enlace con Router 2              | ![[Instalacion_router_10.png]] |

Para **Router 2**, se utilizarán dos adaptadores:

|Adaptador|Conectado a|Función|
|---|---|---|
|Adaptador 1|Red interna `R1-R2`|Enlace con Router 1|
|Adaptador 2|Red interna `RED-INTERNA`|Comunicación con la red interna|

En esta fase únicamente se configurarán los adaptadores virtuales de VirtualBox. Las direcciones IP y el funcionamiento de las interfaces se configurarán posteriormente mediante **NetworkManager**.

## Comprobaciones iniciales

Una vez creada la máquina virtual, se iniciará desde la ISO de Arch Linux.

Al arrancar aparecerá una terminal. En este momento estamos utilizando una **live session**, por lo que todavía no existe un sistema Arch instalado en el disco.

### Comprobar el modo de arranque

Antes de comenzar, comprobaremos que la máquina virtual se ha iniciado utilizando **UEFI**.

Ejecutaremos:

```bash
ls /sys/firmware/efi/efivars
```

Si el comando muestra numerosos archivos y directorios, significa que el sistema se ha iniciado correctamente mediante UEFI.

Si aparece un error indicando que el directorio no existe, se deberá revisar la configuración de la máquina virtual en VirtualBox y comprobar que la opción **EFI/UEFI** está activada.

### Comprobar la conexión a Internet

Arch necesita conexión a Internet durante la instalación para descargar los paquetes necesarios.

Primero comprobaremos que las interfaces de red están disponibles:

```bash
ip link
```

A continuación comprobaremos la conectividad:

```bash
ping -c 3 archlinux.org
```

La opción `-c 3` indica que se enviarán tres paquetes.

Si recibimos respuestas del servidor, significa que existe conectividad.

Para detener una ejecución continua de `ping` se puede utilizar:

```text
Ctrl + C
```

### Comprobar la fecha y hora

Comprobaremos el estado del reloj:

```bash
timedatectl
```

Podemos activar la sincronización automática:

```bash
timedatectl set-ntp true
```

Y comprobar nuevamente el estado:

```bash
timedatectl
```

El objetivo es disponer de una fecha y hora correctas antes de continuar con la instalación.

## Preparación del almacenamiento

Una vez realizadas las comprobaciones iniciales, prepararemos el disco donde se instalará Arch Linux.

> [!WARNING]  
> Los siguientes comandos modifican las particiones del disco. Antes de ejecutarlos debemos comprobar que estamos trabajando sobre el disco virtual correcto.

### Identificar el disco

Para mostrar los discos y particiones disponibles utilizaremos:

```bash
lsblk
```

En nuestra máquina virtual debería aparecer un disco de aproximadamente 15 GB.

El nombre puede variar, por lo que **no debemos asumir que siempre será `/dev/sda`**.

### Crear las particiones

Utilizaremos `cfdisk` para crear las particiones:

```bash
cfdisk /dev/sda
```

Si solicita seleccionar el tipo de tabla de particiones, utilizaremos:

```text
gpt
```

Crearemos dos particiones:

|Partición|Tamaño|Tipo|
|---|--:|---|
|EFI|1 GiB|EFI System|
|Root|Resto del disco|Linux filesystem|

La partición EFI será utilizada por el cargador de arranque y la partición raíz contendrá el sistema Arch Linux.

Una vez creadas, seleccionaremos **Write**, confirmaremos con:

```text
yes
```

y posteriormente seleccionaremos **Quit**.

Podemos comprobar el resultado mediante:

```bash
lsblk
```

## Formatear las particiones

### Partición EFI

La partición EFI se formateará como FAT32:

```bash
mkfs.fat -F 32 /dev/sda1
```

### Partición raíz

La partición principal se formateará como ext4:

```bash
mkfs.ext4 /dev/sda2
```

Podemos comprobar los sistemas de archivos mediante:

```bash
lsblk -f
```

## Montar las particiones

Montaremos primero la partición raíz:

```bash
mount /dev/sda2 /mnt
```

Crearemos el directorio para la partición EFI:

```bash
mkdir -p /mnt/boot
```

Y montaremos la partición EFI:

```bash
mount /dev/sda1 /mnt/boot
```

Comprobaremos los puntos de montaje:

```bash
lsblk
```

## Instalación del sistema base

Con el disco preparado y las particiones montadas, instalaremos los paquetes necesarios:

```bash
pacstrap -K /mnt base linux linux-firmware networkmanager sudo nano
```

Los paquetes instalados son:

|Paquete|Función|
|---|---|
|`base`|Paquetes fundamentales de Arch Linux|
|`linux`|Kernel de Linux|
|`linux-firmware`|Firmware necesario|
|`networkmanager`|Gestión de las interfaces de red|
|`sudo`|Administración mediante privilegios|
|`nano`|Editor de texto|

La opción `-K` prepara el keyring del sistema instalado sin copiar las claves del entorno live.

## Generar el archivo fstab

Generaremos el archivo que permitirá montar automáticamente las particiones durante el arranque:

```bash
genfstab -U /mnt >> /mnt/etc/fstab
```

La opción `-U` utiliza los UUID de las particiones.

Podemos comprobarlo mediante:

```bash
cat /mnt/etc/fstab
```

## Entrar en el sistema instalado

Accederemos al sistema instalado mediante:

```bash
arch-chroot /mnt
```

A partir de este momento, los comandos se ejecutarán sobre el sistema instalado y no sobre la live session.

## Configuración inicial

### Zona horaria

Configuraremos la zona horaria:

```bash
ln -sf /usr/share/zoneinfo/Europe/Madrid /etc/localtime
```

Sincronizaremos el reloj:

```bash
hwclock --systohc
```

### Localización

Editaremos:

```bash
nano /etc/locale.gen
```

Buscaremos:

```text
#es_ES.UTF-8 UTF-8
```

y eliminaremos `#`:

```text
es_ES.UTF-8 UTF-8
```

Generaremos los locales:

```bash
locale-gen
```

Crearemos `/etc/locale.conf`:

```bash
nano /etc/locale.conf
```

Añadiremos:

```text
LANG=es_ES.UTF-8
```

### Nombre del equipo

Para Router 1:

```bash
echo "router1" > /etc/hostname
```

Para Router 2 se utilizará posteriormente:

```bash
echo "router2" > /etc/hostname
```

### Contraseña de root

Estableceremos la contraseña de `root`:

```bash
passwd
```

### Crear el usuario

Crearemos el usuario `ru`:

```bash
useradd -m -G wheel -s /bin/bash ru
```

Estableceremos su contraseña:

```bash
passwd ru
```

### Configurar sudo

Editaremos la configuración de `sudo`:

```bash
EDITOR=nano visudo
```

Buscaremos:

```text
# %wheel ALL=(ALL:ALL) ALL
```

y eliminaremos el `#`:

```text
%wheel ALL=(ALL:ALL) ALL
```

De esta forma, el usuario perteneciente al grupo `wheel` podrá utilizar `sudo`.

## Configurar el cargador de arranque

Instalaremos GRUB y `efibootmgr`:

```bash
pacman -S grub efibootmgr
```

Instalaremos GRUB en la partición EFI:

```bash
grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB
```

Generaremos su configuración:

```bash
grub-mkconfig -o /boot/grub/grub.cfg
```

## Habilitar NetworkManager

NetworkManager ya se instaló durante la instalación del sistema base. Ahora habilitaremos su servicio:

```bash
systemctl enable NetworkManager
```

La configuración de las interfaces, direcciones IP y rutas se realizará posteriormente en las guías específicas de cada router.

## Finalización

Saldremos del entorno `chroot`:

```bash
exit
```

Desmontaremos las particiones:

```bash
umount -R /mnt
```

Finalmente reiniciaremos:

```bash
reboot
```

Antes de que la máquina vuelva a arrancar, retiraremos la ISO de Arch Linux de la unidad óptica virtual de VirtualBox para que el sistema arranque desde el disco virtual.

## Comprobación final

Una vez iniciado Arch Linux desde el disco, iniciaremos sesión con el usuario creado.

Comprobaremos el nombre del equipo:

```bash
hostname
```

Comprobaremos el estado de NetworkManager:

```bash
systemctl status NetworkManager
```

Y las interfaces de red:

```bash
ip link
```

Si el sistema inicia correctamente, podemos iniciar sesión y NetworkManager aparece habilitado y funcionando, la instalación base se considera completada.

A partir de este punto, la configuración se dividirá en dos guías independientes:

- **Configuración de Router 1:** interfaz NAT, DMZ, enlace con Router 2, enrutamiento, NAT, reenvío de paquetes e `iptables`.
    
- **Configuración de Router 2:** enlace con Router 1, red interna, enrutamiento, reenvío de paquetes e `iptables`.
    

Estas configuraciones no se incluyen en esta guía porque dependen de la función específica que desempeña cada router dentro de la infraestructura.
